# Моя первая попытка в модинг :D

## Что делает мод?

Простенький мод, который можно поставить на любой сервер.
В моде есть три приветственных сообщения, триггерное сообщение, сообщение-ответ.

## Можно ли менять сообщения:

Да, можно, в файле конфигурации MyFirstMinecraftMod.json.

## В чём фишка:

Можно поставить на любой сервер и спокойной поменять строчки сообщений. Так же,
во все три строчки сообщения можно подставить триггер %player% и вместо него встанет никнейм игрока.

В версии 1.1 появилась возможность делать перезапуск мода (т.е. Строк) прямо во время запущенной одиночной игры\сервера.
Достаточно ввести в игре /myFirstMinecraftMod reload и строки успешно прочитаются вновь из json и будут использоваться 
новые

## Что нужно вместе с модом:

Fabric API

## Какую версию майнкрафта поддерживает мод?

На данный момент только 1.21.1 с Fabric Loader 0.18.3. Будет работать как на сервере, так и в одиночном режиме.
